
# SKYDIVE LOGBOOK

iOS Application for skydivers. 



## Features

- Create account
- Add / delete/ edit jumps
- Full statistic about all jumps (more 20)
- Add / delete / edit parachute systems
- Calculator loading for canopies
- Create notes

## Frameworks

- UIKit
- UserDefaults
- Realm
- Lottie
- AlertKit



## Localization

The language of the application automatically adjusts to the language of the phone:

- English 
- Russian

The default language is English.
