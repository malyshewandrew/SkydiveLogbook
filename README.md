
# SKYDIVE LOGBOOK

iOS Application for skydivers. 

## Frameworks

- UIKit
- UserDefaults
- NotificationCenter
- Realm
- Lottie
- AlertKit
- SwiftyStoreKit

## Opportunities

- Account
- Statistic (more 20)
- Parachute system
- Calculator loading
- Notes

- ## Features

- Light / Dark theme
- Backup / Restore data
- Localization
- In-app purchases


## Localization

The language of the application automatically adjusts to the language of the phone:

- English 
- Russian

The default language is English.
